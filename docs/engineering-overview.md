# Engineering overview

The private portal exposes `/engineering` and `/api/v1/engineering-overview` as
a read-only index of existing engineering capabilities.

- Health, security and GitOps values come from the same platform status snapshot
  used by the existing `/api/v1/platform` APIs.
- CI/release readiness comes from `evidence/release/release-evidence.json`, which
  is generated by `scripts/release/release-evidence`. The web request never runs
  release checks.
- Toolchain availability means only that an executable is discoverable on the
  portal host. It does not validate its version, credentials, network access or
  production permissions.

Missing, unreadable or uncollected platform inputs are displayed as
**Unavailable**. Release evidence that is absent, malformed, future-dated, or
older than 24 hours is **Not ready**. These states are never converted into a
pass. Generate platform status and release evidence through their existing
documented workflows when current data is needed.
